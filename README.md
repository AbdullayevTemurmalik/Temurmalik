## 🚀 Key Highlights & Architecture

- **Next.js 16 (App Router & Turbopack)**: Blazing fast server-rendered and partial-prerendered architecture (`93/93` static routes generated).
- **11 Full Locales**: Deep native internationalization support (`uz`, `en`, `ru`, `zh`, `es`, `fr`, `ja`, `de`, `it`, `tr`, `ar`).
- **Cinematic GPU Animations**: Silky 950ms–1050ms cascaded scroll reveals using GPU-only transform and opacity transitions for effortless 60/120 FPS on all devices.
- **Lenis Smooth Scrolling**: Frame-rate independent exponential scrolling engine with native scrollbar drag detection and isolated dropdown controls.
- **Strict SEO & Accessibility**: Automated validation script for meta tags, OpenGraph, JSON-LD structured schema, and ARIA compliance.
